# Expo Support Contacts

## Official Support Channels

### 1. Expo Forums (Recommended - Free)
- **URL**: https://forums.expo.dev
- **Best for**: Community help, common issues, build problems
- **Response time**: Usually within hours to a day
- **How to post**: 
  - Include your build ID: `65447913-3c5b-4507-a556-0d5a3bccfb63`
  - Include error logs
  - Tag with `eas-build`, `ios`, `npm-ci`

### 2. Expo Discord (Free)
- **URL**: https://chat.expo.dev
- **Best for**: Quick questions, real-time help
- **Response time**: Usually within minutes to hours
- **Channels**: 
  - `#eas-build` for build issues
  - `#help` for general questions

### 3. GitHub Issues (Free)
- **EAS Build Issues**: https://github.com/expo/eas-cli/issues
- **Expo Issues**: https://github.com/expo/expo/issues
- **Best for**: Bug reports, feature requests
- **Response time**: Varies (days to weeks)

### 4. Expo Support Email (Paid Plans)
- **Email**: support@expo.dev
- **Available for**: 
  - Expo Pro ($29/month)
  - Enterprise plans
- **Response time**: Usually within 24 hours
- **Best for**: Priority support, complex issues

### 5. Expo Status Page
- **URL**: https://status.expo.dev
- **Check for**: Service outages, known issues
